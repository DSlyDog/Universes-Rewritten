# Universes Plugin Changelog

## Version 6.0.0 (Latest Release)
**Major Update with New Features and Bug Fixes**

### 🎉 What's New
- **Complete GUI Rebuild**: The GUI system has been completely rewritten to be more efficient and future proof (hopefully)
- **Enhanced World Management**: Better validation when importing and unloading worlds
- **Improved Compatibility**: Full support for Minecraft 1.21 and newer versions
- **PlaceholderAPI Support**: Improved PlaceholderAPI integration for better stability

### 🛠️ Bug Fixes
- **Fixed End World Generation**: End-type worlds now generate correctly
- **Fixed GUI Issues**: Resolved menu problems that occurred in Minecraft 1.20+
- **Fixed World Import Problems**: Better error messages and duplicate detection
- **Fixed World Unloading**: Worlds now properly unload and won't cause issues
- **Improved Player Tracking**: Better handling of players moving between worlds

### ⚠️ Breaking Changes
- **Economy System Removed**: The built-in economy features have been completely removed
- **Old GUI Code Removed**: Deprecated menu functions have been cleaned up

### 🔧 Technical Improvements
- Updated to support Minecraft 1.21
- Modernized codebase and removed outdated functions
- Better error handling and user feedback
- Improved performance and stability

## Installation Notes
- **Dependencies**:
    - PlaceholderAPI (optional, for enhanced features)
- **Important**: If upgrading from older versions, the economy system has been removed

## Need Help?
If you encounter any issues with this update, please report them on GitHub [here](https://github.com/DSlyDog/Universes-Rewritten/issues).
